# Codebase map

Where to find the code for any given concern. Layer rules and import directions: [layered-packages](layered-packages.md).

## By package

| Package                                             | Entry points worth knowing                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [`packages/shared`](../../packages/shared/src/)     | [`schemas/`](../../packages/shared/src/schemas/) — Zod schemas + types for every entity and I/O shape (`agent.ts`, `run.ts`, `user.ts`, `ids.ts`, `manifest.ts`). [`observability/`](../../packages/shared/src/observability/) — `logger.ts` (pino wrapper), `events.ts` (the closed `LOG_EVENTS` enum).                                                                                                                                                                                                                             |
| [`packages/domain`](../../packages/domain/src/)     | `cost.ts` (model pricing, estimate/actual cost), `schedule.ts` (cron validation), `prompt.ts` (prompt hashing), `grants.ts` (grant-secret ownership check), `errors.ts` (typed domain errors with HTTP status codes). Pure functions, no I/O.                                                                                                                                                                                                                                                                                        |
| [`packages/data`](../../packages/data/src/)         | [`dynamo/`](../../packages/data/src/dynamo/) — `keys.ts` (pk/sk builders), `agents.ts`, `runs.ts`, `users.ts` (repositories), `client.ts` (LocalStack-aware client). [`secrets/`](../../packages/data/src/secrets/) — `anthropic.ts` (per-agent key store/rotate/delete), `grants.ts` (per-agent Notion/GitHub tool-grant secrets). [`s3/`](../../packages/data/src/s3/) — `workspace.ts` (workspace listing + presigned URLs).                                                                                                      |
| [`packages/services`](../../packages/services/src/) | `agent.ts` (agent CRUD use-cases), `runner.ts` (inline run lifecycle: reserve → call Anthropic → finalize → persist), `runner-sandbox.ts` + `sandbox.ts` (sandbox `RunTask` launch + STS session policy), `sandbox-egress.ts` (per-run egress allowlist for the proxy sidecar), `sandbox-grants.ts` (resolve + inject tool grants), `sandbox-lifecycle.ts` (terminal-status mapping), `scheduling.ts` (EventBridge Scheduler upsert/remove + cron dialect conversion), `user.ts` (`ensureProfile`).                                  |
| [`packages/api`](../../packages/api/src/)           | [`handlers/`](../../packages/api/src/handlers/) — one file per route, named exactly as registered in the infra `HANDLERS` array. `middleware.ts` — `withContext()` (JWT context, logging, error translation), `jsonResponse()`.                                                                                                                                                                                                                                                                                                      |
| [`packages/runner`](../../packages/runner/src/)     | `handler.ts` — the single scheduled/invoked Lambda; parses `{agentId}` and delegates to `services/runner.executeRun`.                                                                                                                                                                                                                                                                                                                                                                                                                |
| [`packages/cli`](../../packages/cli/src/)           | `cli.ts` (commander definitions), [`commands/`](../../packages/cli/src/commands/), `auth.ts` (Cognito token storage: OS keychain with plaintext fallback), `config.ts` (persisted `~/.config/agent-village/config.json`), `client.ts` (HTTP client).                                                                                                                                                                                                                                                                                 |
| [`packages/web`](../../packages/web/src/)           | `router.tsx` — **all route registration** (no file-based routing). [`routes/`](../../packages/web/src/routes/) — page components. [`components/`](../../packages/web/src/components/) — UI pieces. [`api-client/`](../../packages/web/src/api-client/) — fetch wrapper + types. [`auth/`](../../packages/web/src/auth/) — Amplify/Cognito wiring. [`e2e/`](../../packages/web/e2e/) — Playwright specs.                                                                                                                              |
| [`packages/infra`](../../packages/infra/src/)       | [`bin/app.ts`](../../packages/infra/bin/app.ts) — stack wiring + cdk-nag suppressions. [`src/stacks/`](../../packages/infra/src/stacks/) — one file per stack (data, auth, api, runner, sandbox, web, monitoring). [`config/`](../../packages/infra/config/) — typed per-env config. [`sandbox-image/`](../../packages/infra/sandbox-image/) — sandbox base image + entrypoint. [`proxy-image/`](../../packages/infra/proxy-image/) — egress-proxy sidecar image (iptables entrypoint + transparent Node proxy + allowlist helpers). |
