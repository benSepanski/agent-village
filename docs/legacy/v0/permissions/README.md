# Permissions

Three-tier list of what an agent (human or LLM) working in this repo may do.

| Tier                            | File                          |
| ------------------------------- | ----------------------------- |
| **Always** — do without asking  | [always](always.md)           |
| **Ask first** — pause and check | [ask-first](ask-first.md)     |
| **Never** — don't do it         | [never](never.md)             |
| How violations are caught       | [enforcement](enforcement.md) |

If you're unsure which tier an action falls into, treat it as **Ask first**.
