# Phase 1, Step 14 — End-to-end test

A single Playwright spec that exercises the full happy path against the deployed `dev` environment.

## File to create

```
packages/web/e2e/mvp.spec.ts
```

(Keep `smoke.spec.ts` from Phase 0 — it stays as the cheapest test.)

## Flow

1. Visit `/`. Get redirected to `/login`.
2. Sign in with a test user (Cognito email/password; seeded by a CI-only setup step).
3. Land on the agent list page; click "Create agent".
4. Fill the form: name, model, system prompt, schedule `*/5 * * * *`, spend limit $1, paste a test Anthropic key (a fake mock the API recognises in dev).
5. Submit; assert the agent appears in the list.
6. Click into the agent; click "Run now".
7. Wait for the Run to appear; assert its status is `ok` and the timeline shows the canonical event sequence.
8. Click "Replay" on the run; assert a second Run with the same model and prompt-hash appears.

## Acceptance

- `pnpm e2e` passes locally against a `pnpm dev` stack.
- `pnpm e2e` passes in CI after a dev deploy — see [`deploy.yml`](../../../.github/workflows/deploy.yml).

## Done!

If all 14 steps pass, Phase 1 is complete. Move to [Phase 2+](../phase-2-plus.md) — but get human review first.
